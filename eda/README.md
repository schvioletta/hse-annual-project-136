# eda

`EDA.ipynb`: сводный EDA команды по чекпоинту 2. Собран из четырёх индивидуальных ноутбуков:

| Файл | Автор | Что вошло в сводный |
|---|---|---|
| `01_eda_nikolaev.ipynb` | Николаев | загрузка через `dayahead.data`, суточный профиль, час x месяц, ACF, остаточная нагрузка, merit-order, остановы АЭС, праздники Венгрии, смена методики прогноза сальдо |
| `Checkpoint_2_EDA_Shcheblykina_Violetta.ipynb` | Щеблыкина | проверки качества, гистограммы признаков, arcsinh-преобразование, сравнение признаков при цене <= 0, лаги со сдвигом 24 ч, ADF, профили признаков по сезонам, круглые значения сальдо |
| `Pismarov_final_version.ipynb` | Писмаров | boxplot цены по месяцу, часу и дню недели; праздники (в сводном календарь Венгрии); идеи признаков для этапа моделей |
| `eda_velem.ipynb` | Велем | ряд с 30-дневным сглаживанием, таблица год x месяц, разбор самых дорогих часов, цена по интервалам температуры |

Данные лежат локально в `data/raw/` и в репозиторий не входят. Запуск из корня репо:

```
uv run jupyter nbconvert --to notebook --execute --inplace eda/EDA.ipynb
```
